# 한판 가로세로 — 수익화 가이드

## 왜 이 구조인가
| 장치 | 역할 |
|---|---|
| **오늘의 퍼즐** (날짜 기반, 전원 동일 문제) | 매일 재방문 이유 + "오늘 몇 분 걸렸어?" 비교 |
| **결과 공유** (이모지 격자, 정답 노출 없음) | 카톡·스레드·X에서 무료 바이럴 = 광고비 0원 유입 |
| **연속 기록 🔥 / 매일 힌트 +1** | 하루 빠지면 손해 → 리텐션 |
| **무한 연습** | 오늘 퍼즐을 다 푼 뒤에도 체류 → 광고 노출 증가 |
| **힌트 부족 → 보상형 광고** | 가장 단가 높은 광고를 사용자가 *원해서* 봄 |
| **전면 광고 (퍼즐 사이, 3분 간격)** | 플레이 도중엔 절대 안 띄움 → 이탈 최소화 |

## 출시 순서 (비용 0원부터)
1. **배포**: 이 저장소 Settings → Pages → `main` 브랜치 → `https://<아이디>.github.io/crossword/daily/`
   - 가능하면 도메인(연 1~2만 원) 연결. AdSense 승인에 유리.
2. **AdSense 신청** → 승인 후 `index.html` 상단 주석 처리된 스크립트를 풀고 `ca-pub-XXXX` 교체.
   - 보상형/전면 광고는 **H5 Games Ads**(adBreak API)로 이미 연결돼 있음. 코드 수정 불필요.
   - 하단 `#adBanner` 를 AdSense `<ins class="adsbygoogle">` 배너로 교체.
3. **앱스토어 진출** (트래픽 확인 후): PWA 그대로 Capacitor로 감싸 Play 스토어 출시 → AdMob 보상형 광고로 교체.
4. **광고 제거 유료화**: `stats.premium = true` 이면 모든 광고가 꺼지도록 이미 구현됨. 결제(토스페이먼츠/Play 결제) 연결만 하면 됨. 권장가 3,900원 1회.

## 현실적인 기대치
- 웹 퍼즐 광고 수익은 대략 **1,000 방문당 1~5천 원** 수준(한국, 배너+보상형 혼합 기준, 편차 큼).
- 하루 1만 명이 오면 월 수십~백만 원대. 핵심은 광고가 아니라 **매일 오는 사람 수** → 공유 기능과 연속 기록이 성장 엔진.
